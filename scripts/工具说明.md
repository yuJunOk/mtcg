# 工具脚本说明

本目录存放用于从官方微信公众号文章中提取规则文本和图片的辅助脚本。当官方更新规则时，可使用这些脚本快速提取新内容。

## 脚本说明

所有规则文档相关的脚本、快照、中间产物统一放在 `scripts/规则文档提取/` 目录下。

### HTML 解析与图片下载

#### `_extract_wechat.js` / `_extract_wechat.py`

解析微信公众号文章 HTML，提取标题、正文文本、图片 URL。

**使用方法**（需先修改脚本内的文件路径）：
```bash
cd scripts/规则文档提取
node _extract_wechat.js    # 或 python _extract_wechat.py
```

JS 版额外支持自动下载图片并生成元数据 JSON。

#### `_download_images.js`

从 HTML 文件中提取图片 URL 并下载到指定目录，支持文件名前缀。

```bash
cd scripts/规则文档提取
node _download_images.js <html文件> <输出目录> [前缀] [图片格式]

# 示例（带前缀，避免多目录图片混淆）
node _download_images.js _temp_qa1.html ../docs/规则文档/QA图片-第1期 qa1- png
```

### OCR 文字识别

#### `_ocr_recognize.js`

对指定目录下的图片做中文 OCR 识别，输出到文本文件。依赖 `tesseract.js`（在父级 `node_modules` 中）。

```bash
cd scripts/规则文档提取
node _ocr_recognize.js <图片目录> <输出文件>

# 示例
node _ocr_recognize.js ../docs/规则文档/QA图片-第1期 qa1_ocr.txt
```

`chi_sim.traineddata` 为中文简体训练数据，`_ocr_recognize.js` 通过 `langPath` 指定同目录加载，无需联网下载。

## 官方更新流程

当官方发布新的规则文章时：

1. **保存网页源代码**为 `规则文档提取/_temp_*.html` 文件
2. **运行提取脚本**：`规则文档提取/_extract_wechat.js`（或 Python 版）
3. **整理规则文本**，更新 `docs/规则文档/` 下对应的 `.md` 文档
4. **更新版本号**和来源链接

如果新文章是对现有规则的修订（如 v1.01 -> v1.02）：
- 更新现有文档中的条款内容
- 在文档头部更新版本号和日期
- 在附录中添加更新日志

如果新文章是规则 Q&A（新的一期）：

1. **下载网页**：用 PowerShell `Invoke-WebRequest` 下载文章 HTML 到 `scripts/规则文档提取/`
2. **提取图片**：`cd scripts/规则文档提取 && node _download_images.js _temp_qa{N}.html ../docs/规则文档/QA图片-第{N}期/ qa{N}-`
3. **OCR 识别**：`cd scripts/规则文档提取 && node _ocr_recognize.js ../docs/规则文档/QA图片-第{N}期/ qa{N}_ocr.txt`
4. **人工校对**：对照 OCR 结果和原图，修正识别错误（卡牌名、术语等）
5. **创建文档**：在 `docs/规则文档/` 下新建 `05-规则Q&A-第{N}期.md`，格式参考第一期
6. **更新索引**：在 `README.md` 的来源表、文档索引、路线图、更新历史中补充条目
