# 工具脚本说明

本目录存放 MTCG 项目的辅助工具脚本。

> ★ **补充卡牌素材请先看**：[卡牌素材补充指南](../docs/设计文档/卡牌素材补充指南.md)  
> （官网拉取 / 截图补齐 pipeline / 统一 1488×2080 / 共享 seed SQL）

## 目录结构

```
scripts/

├── package.json / package-lock.json
│
├── card_common/              # ★ 共享：规格 normalize + seed_sql
│   ├── spec.py / normalize.py / normalize_cli.py
│   └── seed_sql.py           # 官网整包 & 按产品拆分 INSERT
│
├── 官网卡表拉取/             # 流程 A：API → faces + seed-official-cards.sql
│   ├── fetch_cards.py
│   └── out/
│
├── 卡面提取/                 # 流程 B：截图 → faces + seed-cards/
│   ├── extract_card.py
│   ├── pipeline.py           # prepare / apply / sql
│   ├── catalogs/             # catalog 存档
│   └── run_extract.bat
│
└── 规则文档提取/             # 微信规则文章（Node.js）
    ├── extract.js / download.js / ocr.js
    └── lib/
```

## 卡牌素材（最常用）

```bash
# A. 官网
python scripts/官网卡表拉取/fetch_cards.py

# B. 截图补齐
python scripts/卡面提取/pipeline.py prepare assets/card/raw -o assets/card/extracted/batch1
# 编辑 catalog.json 后：
python scripts/卡面提取/pipeline.py apply assets/card/extracted/batch1/catalog.json
```

细节见指南与各子目录 README。

## 规则文档提取

### 1. 安装依赖

```bash
cd scripts && npm install
```

### 2. 准备微信文章

浏览器打开文章 → 右键「查看网页源代码」→ 全选复制 → 保存为 `.html`

### 3. 提取 / 下图 / OCR

```bash
cd scripts/规则文档提取
node extract.js <文章.html>
node download.js <文章.html> <输出目录> [图片前缀] [格式]
node ocr.js <图片目录> <输出文件>
```

官方规则更新、Q&A 流程同前：解析 HTML → 下图 → 整理进 `docs/规则文档/`。
