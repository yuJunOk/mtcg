# 工具脚本说明

本目录存放 MTCG 项目的辅助工具脚本。

---

## 目录结构

```
scripts/
├── 工具说明.md              # 本文件
├── package.json             # npm 依赖（tesseract.js）
├── package-lock.json
│
├── 卡面提取/               # 卡面截图批量提取工具
│   ├── README.md           # 使用说明
│   ├── extract_card.py     # 核心提取脚本（Python）
│   ├── run_extract.bat     # 一键运行脚本
│   └── fix_execution_policy.reg # PowerShell 执行策略修复
│
├── 规则文档提取/             # 规则文档提取全流程
│   ├── README.md           # 工具说明
│   ├── _extract_wechat.js  # 解析微信文章 HTML（JS）
│   ├── _download_images.js # 下载 HTML 中的图片
│   ├── _ocr_recognize.js  # 中文 OCR 识别
│   ├── chi_sim.traineddata # tesseract 中文训练数据
│   └── qa1_ocr.txt        # Q&A 第一期 OCR 结果
│
└── 归档/                    # 历史文件归档
    ├── README.md
    ├── _temp_quickstart.html # 快速入门文章快照
    ├── _temp_rules.html     # 综合规则书文章快照
    └── _extract_wechat.py   # 已废弃的 Python 版（保留参考）
```

---

## 官方更新流程

当官方发布新的规则文章时：
1. **保存网页源代码**：浏览器打开文章 → 右键「查看网页源代码」→ 保存为 `.html` 放入 `归档/`
2. **复制快照到工作区**：复制到 `规则文档提取/` 下的 `_temp_*.html`
3. **运行提取脚本**：`规则文档提取/_extract_wechat.js`
4. **整理规则文本**，更新 `docs/规则文档/` 下对应的 `.md`
5. **更新版本号**和来源链接

如果新文章是规则 Q&A（新的一期）：
1. `cd scripts/规则文档提取 && node _download_images.js _temp_qa{N}.html ../docs/规则文档/QA图片-第{N}期/ qa{N}-`
2. `node _ocr_recognize.js ../docs/规则文档/QA图片-第{N}期/ qa{N}_ocr.txt`
3. 人工校对，修正识别错误
4. 在 `docs/规则文档/` 下新建 `05-规则Q&A-第{N}期.md`
5. 更新 `docs/规则文档/README.md` 的索引
