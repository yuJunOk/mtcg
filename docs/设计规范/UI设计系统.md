# MTCG UI 设计系统

> 本文件是 MTCG **游戏端（game-pc / game-mobile）** 前端 UI 的唯一设计标准。  
> 管理后台（admin-web）使用 Element Plus 默认主题，不套用本文游戏端规范。
>
> **设计理念**：清爽 · 高级 · 卡面优先 · 双主题同品牌  
> **主视觉**：官网式大气英雄区 + 构筑页左卡表 / 右固定尺寸竖卡池。  
> **主题策略**：`light` 贴近 [官网](https://www.marvelherorush.com/) 的明亮大气；`dark` 为可选。经 `data-theme` + Pinia `themeStore` 切换。

---

## 1. 设计理念

### 1.1 核心原则

| 原则 | 说明 |
| --- | --- |
| **卡面优先** | UI 服务于卡牌；卡面占屏比要高，壳层控件不抢戏 |
| **清爽** | 每屏核心信息 5–9 项；高级筛选默认折叠。清爽 ≠ 空：主次入口、卡面占屏、统一壳层要有重量 |
| **高级** | 靠对齐、层级、卡面与主 CTA，不靠渐变底、芯片墙、多层 glow |
| **双主题同品牌** | 明暗共用同一强调色相（青绿），禁止亮色另起珊瑚橙等「第二品牌色」 |
| **卡面不变形** | 卡面固定宽高（`--card-face-w/h`），容器滚动；禁止用剩余视口高度去平分卡面 |
| **大气** | 首页英雄区占大半屏；字号与留白向官网看齐，不做挤满的工具后台 |
| **性能优先** | 主题用 CSS 变量；动画只用 `transform` / `opacity` |

### 1.2 对标谁

| 借鉴 | 取舍 |
| --- | --- |
| [超英击战官网](https://www.marvelherorush.com/)：全幅英雄图、大标题、留白、明亮 | 壳层与首页氛围；官网无暗色，我们暗色作为可选项 |
| [DECK LOG](https://decklog.bushiroad.com/)：卡面固定像素、列表滚动、点选加减 | 构筑页卡池与卡表 |
| TCG PORTAL：左卡表（缩略图+名+数量）+ 右竖卡网格 | 构筑分栏 |
| Arena：顶栏工具条 | 顶栏节奏 |
| 官网卡表：罕度/等级/距离芯片 | 放进**高级筛选**，默认不展开 |

### 1.3 反模式黑名单（禁止）

- 多段径向渐变铺满页面背景
- 默认展开的「芯片墙」占据首屏
- 卡面用 `minmax(..., 1fr)` / `flex: 1` / `height: 100%` 去填剩余高度，导致裁切
- `object-fit: cover` 用在比例不锁定的卡面盒上
- 构筑左栏用空槽马赛克占满屏，或纯文字无缩略图
- 明暗主题强调色色相不一致
- 大面积 `--shadow-glow` 装饰非选中态
- 一屏堆砌假运营模块（假排行、假社区、多 CTA 抢焦点）
- 页面内私自写死主色（必须用 token）

### 1.4 适用场景

| 场景 | 主题 | 样式来源 |
| --- | --- | --- |
| game-pc / game-mobile 外壳 | dark / light | `theme-base.css` + `theme-dark.css` / `theme-light.css` |
| Pixi 对战画布 | 跟随主题语义色 | 见 §8 |
| admin-web | Element Plus 默认 | 不套用本文色板 |

### 2.3 使用规则

| 元素 | Token |
| --- | --- |
| 页面背景 | `--bg-base`（纯色，禁止花哨径向底） |
| 面板 | `--bg-surface` |
| 主按钮 | `--accent`，文字用深色 `#0B1220`（暗）/ `#FFFFFF`（亮，对比不足时用白） |
| 次按钮 | 透明或 `--bg-surface-2` + `--border` |
| 危险 | `--accent-red` |
| 正文 / 辅助 | `--text-primary` / `--text-secondary` |

> **红色禁令**：常规导航、统计、标签不用红。

### 2.4 主按钮文字色约定

- 暗色主题：主按钮文字 `#0B1220`（压在亮青绿上）
- 亮色主题：主按钮文字 `#FFFFFF`

可用变量：`--accent-contrast`（见 theme 文件）。

| 层级 | 背景 | 阴影 | 场景 |
| --- | --- | --- | --- |
| 0 | `--bg-base` | 无 | 页底 |

## 6. 卡面规格（强制）

卡面 **宽高由 token 锁死**，多出来的张数在容器里 **滚动**。视口变矮时，卡面尺寸不变。

| 项 | 规格 |
| --- | --- |
| 比例 | 1488∶2080 |
| 池内卡 | `--card-face-w` × `--card-face-h`（约 156×218） |
| 列表封面 | `--card-cover-w` × `--card-cover-h` |
| 行内缩略图 | `--card-thumb-w` × `--card-thumb-h` |
| 网格列 | `repeat(auto-fill, var(--card-face-w))`，**禁止** `minmax(..., 1fr)` |
| 行高 | `grid-auto-rows: max-content`；`align-content/items: start` |
| 图片 | `object-fit: contain`；盒尺寸已等于卡比，不会裁、不会拉 |
| 容器 | `overflow-y: auto`；`min-height: 0`（让 flex 子项真能滚） |
| 悬停 | 边框切 `--accent`；`translateY(-2px)` ≤ 150ms |

## 7. 组件

### 7.1 按钮

| 类型 | 样式 |
| --- | --- |
| 主按钮 | `--accent` 底，高 `--ctrl-h`，圆角 `--radius-sm` |
| 次按钮 | 透明 + `--border` |
| 文字按钮 | 无边框，`--text-secondary`，hover → `--accent` |
| 危险 | 文字/边框用 `--accent-red`（列表操作用文字按钮即可） |

### 7.2 输入

高 `--ctrl-h`；底 `--bg-surface-2`；边 `--border`；focus 用 `--shadow-glow`（细环，非光晕团）。

### 7.3 芯片（仅高级筛选）

高度 26–28px；`全部` + 单选互斥；选中：`--accent` 边与字，浅底。

### 7.4 弹窗壳（`MtcgDialog`）

业务弹窗必须基于 `game-pc` 的 `MtcgDialog`，结构固定：

```
┌──────────────────────────────┐
│ 标题              [全屏?] [X] │  ← 标题行（弹窗头）
├──────────────────────────────┤
│                              │
│  内容区（定高，overflow 滚动） │
│                              │
├──────────────────────────────┤
│              [取消]  [确定]   │  ← 底栏右侧
└──────────────────────────────┘
```

| 区域 | 规则 |
| --- | --- |
| 标题行 | 左侧标题；右侧可选全屏 + 关闭 X；不要把说明文案塞进标题行 |
| 内容区 | `bodyHeight` 定高（默认约 `min(56vh, 480px)`）；内部滚动；全屏时撑满剩余高度 |
| 底栏 | 右对齐「取消 / 确定」；确定文案可按场景覆盖（如「开始对战」） |
| 全屏 | 仅在内容易溢出、需要更大工作区时开启 `fullscreenable` |

「与 AI 对战」等内容：对阵封面 + AI 卡组横选 + 难度/倾向/先后手段控，全部放在内容区滚动。

## 8. 页面线框

登录 / 对战画布 **不套** 游戏壳。首页、卡组列表、匹配大厅、卡表套 `GameLayout`（同一顶栏）。构筑页用自己的工具条（全宽工作区）。

**壳内工具页页头**：一行即可（标题 ± 主操作 ± 一行短 hint）。禁止「分类 kicker + 超大 H1 + 说明段」三层头——顶栏已有导航语境，大气英雄区只留给首页。

### 8.1 登录

```
┌──────────────┬───────────────────┐
│ MARVEL       │  登录             │
│ 超英击战      │  表单…            │
│ 一句品牌     │  [进入游戏]        │
└──────────────┴───────────────────┘
```

左右分栏：左品牌（氛围图 + 大标题）、右表单。窄屏改为上下堆叠。

### 8.2 首页壳（大厅）

对标 [超英击战官网](https://www.marvelherorush.com/) 的**大气英雄区**（全幅图、大标题、页面滚动）：

```
┌─ 顶栏全宽 ───────────────────────────────────────┐
│  英雄区：氛围图 + MTCG 大标题 + CTA · 右叠三巨头（居中、约半屏高） │
│  卡表/商品/排行弱入口                                                │
│  ── 我的卡组          全部 → ────────────────── │
│  横带（无封面 🃏；两侧翻页每次一张）                  │
│  ── 商品系列（无图 📦；两侧翻页每次一张） ────────── │
└─────────────────────────────────────────────────┘
```

- 顶栏品牌文案：**MTCG**；英雄区 H1 同为 MTCG，kicker 用「超英击战」
- 英雄区垂直居中、高度约 `52vh`（勿再贴底留大片空白）；状态 hint 放 CTA 下
- 英雄区下用弱链（卡表/商品/排行），勿重复出战入口
- **主入口只在英雄区**：开始对战 / 管理卡组；禁止再做「对战 / 卡组」快捷砖
- 英雄区右侧叠卡：固定复联三巨头真卡面；禁止用卡背 / 先后手草稿图
- 无封面：卡组 🃏；商品 📦
- 只用真实卡组 / 产品数据，禁止假运营模块
- 顶栏全宽；内容区内宽 `--shell-max`

### 8.3 卡组列表

```
┌─ 同一顶栏 ──────────────────────────────────────┐
│  我的卡组 · 短 hint          [新建卡组]          │
│  ┌─────┐ ┌─────┐ ┌─────┐                        │
│  │封面 │ │封面 │ │封面 │   瓦片网格              │
│  │名称 │ │名称 │ │名称 │                        │
│  └─────┘ └─────┘ └─────┘                        │
└─────────────────────────────────────────────────┘
```

内容宽 ≤ `--shell-max`；页头单行（约 20px 标题），不堆 kicker。封面由玩家指定一张卡（`coverCardCode`），图走 `coverImagePath`。合法卡组提供「出战」（进备战室）；校验/删除为封面下文字操作，不盖住卡面。无封面（或图加载失败）用 🃏；商品无图用 📦。列表空状态纯文字。新建只保留页头按钮。

### 8.4 构筑（核心）

```
┌─ ← 名称 · 主 n/50 · 冲击 n/9 · 校验 保存 ─┐
├──────────────────┬──────────────────────────┤
│ 主卡组 行列表     │ 搜索 · 系列 · 颜色 · 高级 │
│ 缩略图 + 名 + ±   │  卡池竖卡大网格（无卡名条）│
│ 冲击 行列表       │  分页                    │
└──────────────────┴──────────────────────────┘
```

- 左：固定 `--deck-col`（约 300px）；右：`--pool-col` 占满剩余
- 左栏为**带卡面缩略图的行列表**（非空槽马赛克、非纯文字）
- 右栏卡池：`--card-face-w/h` 锁死，`overflow-y: auto` 滚动；禁止 `1fr` 平分高度
- 保存时弹出封面选择：从主卡组角色卡里点一张，再确定保存

### 8.5 匹配大厅（备战室）

套 `GameLayout`。不是说明页，是出战准备：

```
┌─ 大封面（选中合法卡组） ─┬─ 名称 · 合法 · 主/冲击 ─┐
│                          │  [在线匹配]               │
│                          │  [创建房间]               │
│                          │  [与 AI 对战]             │
│                          │  对局 ID [加入]           │
└──────────────────────────┴───────────────────────────┘
── 可出战卡组（横带点选） ────────────────────────────
```

- 主 CTA：「在线匹配」。匹配不到：建议创建房间，或打开「与 AI 对战」配置弹窗
- 「与 AI 对战」：基于 `MtcgDialog`（标题行 + 定高可滚内容 + 底栏取消/开始对战）；内容为对阵封面 + AI 卡组横选 + 段控
- 创建房间：只提交本人卡组，得到对局 ID，轮询等待对手加入
- 无合法卡组：文字空状态 + 引导去构筑，不用卡背草稿图
- 封面锁死宽高（约 240×卡比），`object-fit: contain`；无封面用 🃏，不用卡背垫

### 8.6 卡表（图鉴）

对标 [官网卡表](https://www.marvelherorush.com/cn/cards)。套 `GameLayout`。

```
┌─ 同一顶栏 ──────────────────────────────────────┐
│  卡表（单行标题）                                 │
│  搜索 · 系列 · 颜色点 · 高级筛选 · 共 n 条        │
│  [高级：类型 / 罕度 / 等级 / 距离 / 特征]         │
│  ┌────┐ ┌────┐ ┌────┐  固定尺寸网格 · 分页      │
└─────────────────────────────────────────────────┘
```

- 页头只要「卡表」二字，勿再加图鉴 kicker / 说明段
- 高级筛选默认折叠；罕度 / 等级 / 距离芯片不占首屏
- 卡面宽高走 `--card-face-*`，`object-fit: contain`，禁止 `1fr` 填高
- 点卡打开 `MtcgDialog`：左大卡面 + 右属性/效果；可全屏
- 首页商品系列点进本页并带 `?product=`

### 8.7 商品

对标 [官网商品页](https://www.marvelherorush.com/cn/products)。套 `GameLayout`。

```
┌─ 同一顶栏 ──────────────────────────────────────┐
│  商品（单行标题）                                 │
│  全部 / 基础卡组 / 补充包 / 其他 · 共 n 条         │
│  ┌────┐ ┌────┐  封面 + 分类 + 名【编号】+ 发售日  │
└─────────────────────────────────────────────────┘
```

- 页头单行；分类由 `productCode` 前缀推断（SD→基础卡组，BP→补充包，其余→其他），后端暂无 category 字段
- 点商品进卡表并带 `?product=`
- 无封面用 📦（勿用首字母 label 盖掉 emoji）
- 商品图为 `imagePaths: string[]`（首张作列表封面）；管理端可多张追加/单张删除

### 8.8 对战页 Vue 壳

画布外 UI（顶栏、认输、阶段提示）使用同一 token；HUD 半透明，不做成网站底栏。禁止假计时、禁止用 `min-height` 撑出整页滚动。  
区域槽用 `--bg-surface-2` + 内阴影做成**刻入桌面**的空槽，禁止斜纹底、靛/绿/橙私货色。Pixi 内色值与 §2 对齐。

## 10. 动画

- 默认 ≤ 150ms；复杂 ≤ 250ms；禁止 > 400ms 的装饰动画
- 仅 hover / 选中 / 路由过渡
- 只用 `transform` + `opacity`

## 13. AI / 实现检查清单

- [ ] 背景 `--bg-base` 纯色，无多段径向装饰底
- [ ] 面板 `--bg-surface*`，文字 `--text-*`
- [ ] 主强调 `--accent`，明暗同色相；红仅危险/战斗
- [ ] 主按钮文字用 `--accent-contrast`
- [ ] 圆角 / 间距 / 顶栏高度走 token
- [ ] 构筑：左缩略图行表 + 右固定尺寸竖卡池（容器滚动）；高级筛选默认折叠
- [ ] 卡面宽高走 `--card-face-*`，`object-fit: contain`，无 `1fr` 填高
- [ ] 登录/首页/卡组/大厅壳层统一（构筑、对战除外）
- [ ] 卡组列表：单封面瓦片网格，无行式表、无重叠马赛克
- [ ] 壳内工具页（卡组/卡表/备战室）：单行标题，禁止 kicker+大 H1+说明三层头
- [ ] 首页：英雄区主 CTA + 状态行；卡组无封面 🃏、商品无图 📦；横带两侧翻页每次一张；卡表可进
- [ ] 卡表：搜索/系列/颜色在主栏，高级筛选默认折叠；卡面固定尺寸；点卡弹窗看效果
- [ ] 匹配大厅：备战室（大封面 + 在线匹配 / 创建房间 / 与 AI 对战）；弹窗符合 §7.4
- [ ] 商品：分类芯片 + 封面瓦片；点进卡表带系列筛选；无图 📦
- [ ] 业务弹窗用 `MtcgDialog`：标题行 X（可选全屏）、内容定高可滚、底栏右对齐取消/确定
- [ ] 卡组列表：出战 CTA；操作不盖卡面；无封面用 🃏；列表空状态纯文字
- [ ] 对战场槽位走 token，无斜纹/私货色；无假计时、无强制 950px 滚动
- [ ] 默认 UI 不用大面积 glow
- [ ] 页面私货主色 = 违规
