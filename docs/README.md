## 文档使用指南

1. **新手入门**：先读规则文档「01-快速入门规则」
2. **当前开发**：读 `AGENTS.md` 当前迭代对应的详细设计 + 实现步骤
3. **查阅规则**：开发时查阅「03-术语表与关键词速查」
4. **引擎开发**：重点读「04-区域模型与回合流程」
5. **效果开发**：读「08-详细设计-迭代六-效果系统与关键词能力」

## 文档维护规范

- 规则更新时，同步更新 `02-综合规则书` 版本号
- 每次迭代完成后：更新对应详细设计/实现步骤状态，并同步 `AGENTS.md`「当前迭代」与根 `README.md`
- 编码规范调整时，同步更新前后端 AI 编码规范
- 迭代编号统一为：七=对战API / 八=AI / 九=排位 / 十=系统管理
