## 文档使用指南

1. **新手入门**：先读规则文档中的「01-快速入门规则」
2. **后端开发**：读「02-综合规则书」+「03-术语表」+「04-区域模型」，然后进入「详细设计-迭代一」开始编码
3. **查阅规则**：开发时随时查阅「03-术语表与关键词速查」快速找枚举和关键词
4. **引擎开发**：重点读「04-区域模型与回合流程」，里面有状态模型和距离矩阵
5. **效果开发**：读「08-详细设计-迭代六-效果系统与关键词能力」
