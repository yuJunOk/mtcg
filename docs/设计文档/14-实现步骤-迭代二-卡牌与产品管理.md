## 步骤详解

### 步骤 1：后端 - ErrorCode 补充

**文件**：`common/result/ErrorCode.java`

**设计理由**：建立卡牌/产品专属错误码域（3001-3099），便于分类处理和日志追踪。与用户域（1001-1099）、引擎域（2001-2999）形成清晰划分。

```java
// === 卡牌/产品领域（3001-3099）===
CARD_NOT_FOUND(3001, "卡牌不存在"),
CARD_CODE_DUPLICATE(3002, "卡牌编号已存在"),
PRODUCT_NOT_FOUND(3003, "产品不存在"),
PRODUCT_CODE_DUPLICATE(3004, "产品编号已存在"),
```

**检验方式**：`mvnw.cmd compile` 通过。

---

### 步骤 2：后端 - CardServiceImpl 补充 ErrorCode

**文件**：`service/impl/CardServiceImpl.java`

**设计理由**：`createCard` 中的编号重复检测改用 `CARD_CODE_DUPLICATE`；`loadOrThrow` 改用 `CARD_NOT_FOUND`。保持错误码域一致。

```java
// createCard 中：
if (count > 0) {
    throw new BusinessException(ErrorCode.CARD_CODE_DUPLICATE);
}

// loadOrThrow 中：
if (card == null) {
    throw new BusinessException(ErrorCode.CARD_NOT_FOUND);
}
```

同时：
- `createProduct` 中的编号重复检测 → `ErrorCode.PRODUCT_CODE_DUPLICATE`
- `loadOrThrow` → `ErrorCode.PRODUCT_NOT_FOUND`

**检验方式**：`mvnw.cmd compile` 通过；Swagger 测试重复编号创建返回 3002。

---

### 步骤 3：后端 - ProductService 接口新增

### 步骤 4：后端 - ProductController 新增接口

**文件**：`controller/ProductController.java`

**设计理由**：RESTful 风格，产品下的卡牌用子资源路径 `/products/{productCode}/cards`，语义清晰。

```java
@Operation(summary = "按产品编号查询卡牌列表")
@GetMapping("/{productCode}/cards")
public Result<PageVO<CardVO>> listCardsByProduct(
        @PathVariable String productCode,
        @RequestParam(required = false) Integer page,
        @RequestParam(required = false) Integer size) {
    return Result.success(productService.listCardsByProduct(productCode, page, size));
}
```

---

### 步骤 5：后端 - ProductServiceImpl 实现 listCardsByProduct

**文件**：`service/impl/ProductServiceImpl.java`

```java
@Resource
private CardMapper cardMapper;

@Override
public PageVO<CardVO> listCardsByProduct(String productCode, Integer page, Integer size) {
    QueryWrapper qw = QueryWrapper.create()
            .eq("product_code", productCode)
            .orderBy("create_time", false);
    int pageNum = (page == null || page < 1) ? 1 : page;
    int pageSize = (size == null || size < 1) ? 20 : size;
    Page<CardDO> result = cardMapper.paginate(Page.of(pageNum, pageSize), qw);
    List<CardVO> records = result.getRecords().stream()
            .map(this::cardToVO)
            .collect(Collectors.toList());
    return new PageVO<>(records, result.getTotalRow());
}
```

**检验方式**：`mvnw.cmd compile` 通过。

### 步骤 6：前端 - adminApi 新增 listCardsByProduct

**文件**：`packages/common/src/api/adminApi.ts`

**设计理由**：产品管理模块下新增查询方法，与 `adminProductApi.list` 保持风格一致。类型从 `../types/card` 导入（`CardVO` + `PageVO`）。

```ts
// 在 adminProductApi 末尾新增：
listCardsByProduct: (productCode: string, page?: number, size?: number) =>
  axios.get<Record<string, unknown>>(
    `/admin/products/${productCode}/cards`,
    { params: { page, size } }
  ).then(r => extractData<PageVO<CardVO>>(r))
```

**检验方式**：`npm run dev:admin` 编译无 TS 报错。
