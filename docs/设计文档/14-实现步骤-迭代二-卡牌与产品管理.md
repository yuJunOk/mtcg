# 迭代二：卡牌与产品管理

> 目标：交付「管理后台能录入维护卡牌和产品」的最小闭环。
>
> 前置依赖：迭代一（鉴权基础设施 + 枚举 + 建表）
>
> **as-built 说明**：
> - 实际新增表：`mtcg_card_feature`、`mtcg_card_feature_rel`、`mtcg_audit_log`（特征体系 + 审计雏形）
> - Schema 脚本：`sql/init-schema.sql` / `init-data.sql`（非旧文档中的 `init.sql`）
> - 公开控制器命名：`CardController` / `ProductController`（非 `Public*`）
> - 按产品查卡：`productApi.listCards` → `GET /products/{productCode}/cards`
> - **未做**：卡牌批量导入（原设计延后）
> - **不做**：独立 Tag 模块（以 CardFeature 关联替代）
