# 卡牌素材补充指南

> **用途**：以后补充卡图 / 卡表数据时只看本文即可。  
> **相关脚本**：`scripts/官网卡表拉取`、`scripts/卡面提取`、`scripts/card_common`  
> **最后更新**：2026-08-12

---

## 1. 一句话结论

| 来源 | 何时用 | 脚本 |
|------|--------|------|
| 官网卡表 API | 已有系列的角色卡（BP/SD 等） | `scripts/官网卡表拉取/fetch_cards.py` |
| APP/其他平台截图 | 官网没有的 **冲击卡 RP**、**推广包 PR** 等 | `scripts/卡面提取/extract_card.py` |
| 统一修规格 | 任意已有 PNG 去透明边、统一尺寸 | `scripts/card_common/normalize_cli.py` |

**最终入 UI / SQL 的卡图**一律放在：

```text
assets/card/official/{系列}/{编号}-{罕度}.png
```

例如：`assets/card/official/BP01/BP01-001-MR.png`、`assets/card/official/RP01/RP01-001-C.png`

> `assets/card/official/` 已加入 `.gitignore`（体积大 + 版权），只保存在本地，勿提交 Git。

---

## 2. 统一画布规格（两边必须一致）

| 项 | 值 |
|----|----|
| 尺寸 | **1488 × 2080** |
| 格式 | RGBA PNG |
| 透明边 | **无**（四周 pad = 0，仅圆角透明） |
| 圆角 | 宽 × `41/747` ≈ **82px**（与截图提取标定一致） |

流水线（`scripts/card_common`）：

```text
去透明边 → 等比缩放并居中贴到 1488×2080 → 统一圆角
```

常量定义：`scripts/card_common/spec.py`  
实现：`scripts/card_common/normalize.py`

## 3. 目录约定

```text
assets/card/
├── raw/                      # 截图原图（按系列分子目录可选）
│   ├── SD04-时间/
│   ├── RP01/                 # 冲击卡截图
│   └── PR01/                 # 推广包截图
├── extracted/                # 截图提取中间结果（可选）
└── official/                 # ★ 最终卡图（UI + image_path）
    ├── BP01/
    ├── SD01/ … SD04/
    ├── RP01/                 # 截图补齐
    └── PR01/                 # 截图补齐
```

种子数据（可提交 Git）：

| 文件 | 说明 |
|------|------|
| `scripts/官网卡表拉取/out/cards.json` | 官网卡牌 JSON |
| `scripts/官网卡表拉取/out/products.json` | 产品 JSON |
| `mtcg-server/src/main/resources/sql/seed-official-cards.sql` | 幂等 INSERT SQL |

库表字段对应：`mtcg_card.image_path = card/official/{系列}/{card_code}.png`

## 4. 命名规则

| 项 | 规则 | 示例 |
|----|------|------|
| `card_code` / 文件名 | `{基础编号}-{罕度}` | `BP01-001-MR` |
| 基础编号 | 同角色同版本编号相同 | `BP01-001` |
| 罕度 | 与库枚举一致：C/R/SR/GR/UR/MR/SEC/PR/ER/TR… | `MR` |
| 系列目录 | = `product_code` | `BP01`、`RP01` |

同一编号多罕度（异画）= **多条记录、多张图**，例如：

- `BP01-001-MR.png`
- `BP01-001-SEC.png`
- `BP01-001-UR.png`

## 5. 流程 A：官网卡表（优先）

官网：[超英击战卡表](https://www.marvelherorush.com/cn/cards)  
API：`https://server.marvelherorush.com`（`/marvel/card/list`、`/marvel/product/list`）

在仓库根目录：

```bash
# 拉元数据 + 下图 + 自动规范化到 1488×2080 + 生成 SQL/JSON
python scripts/官网卡表拉取/fetch_cards.py

# 仅 JSON/SQL
python scripts/官网卡表拉取/fetch_cards.py --skip-images

# 强制重下全部卡图
python scripts/官网卡表拉取/fetch_cards.py --force-images

# 并发（CDN 易断流，建议 2～3）
python scripts/官网卡表拉取/fetch_cards.py --workers 2
```

Windows 若 PATH 无 Python，可用：

```text
D:\ProgramApp\Python\python-3.13.14\python.exe
```

说明：

- 下载用 **Range 分片**，并校验 PNG 完整性；残缺图会自动重下。
- 下载后自动 normalize；已是统一规格的会跳过。
- 官网当前可能 **只有角色卡**，冲击卡 / 部分推广包需走流程 B。

详细脚本说明：`scripts/官网卡表拉取/README.md`

## 6. 流程 B：截图补齐（RP / 推广包等）

### 6.1 截图

1. 在 APP 或其他平台打开卡详情，全屏截图。
2. 放入 `assets/card/raw/{系列}/`（系列目录名随意，便于整理即可）。

裁切框默认按 **1080×2354** 安卓截图标定，其他分辨率会按比例缩放；对不齐时用 `--left/--top/--right/--bottom` 微调。

### 6.2 提取并规范化

```bash
# 双击 scripts/卡面提取/run_extract.bat
# 或：
python scripts/卡面提取/extract_card.py assets/card/raw -o assets/card/extracted
```

输出默认已是 **1488×2080**。

### 6.3 改名入库目录

把文件改成 `{编号}-{罕度}.png`，放进 `assets/card/official/{系列}/`：

```bash
# 若 extracted 里已是正确文件名，可直接规范化输出到系列目录
python scripts/card_common/normalize_cli.py assets/card/extracted -o assets/card/official/RP01
```

### 6.4 补 SQL / 产品

官网脚本不会自动生成 RP/推广包的 INSERT。需手工或另写种子：

1. 若有新系列：先 `INSERT` `mtcg_product`（`product_code` / `product_name`）。
2. 再 `INSERT` `mtcg_card`，`image_path` 指向 `card/official/{系列}/{card_code}.png`。
3. 字段映射可参考 `seed-official-cards.sql` 与 `cards.json`。

颜色：`红色→RED` 等；类型：`character→CHARACTER`，冲击卡 → `RUSH_POINT`；等级：`LV3→3`。

详细脚本说明：`scripts/卡面提取/README.md`

## 9. 常见问题

| 现象 | 处理 |
|------|------|
| 图只有一截 / 打不开 | 重跑 `fetch_cards.py`（残缺会重下）；或删坏图后再跑 |
| 四周有透明边、UI 对不齐 | `normalize_cli.py assets/card/official` |
| 截图裁切偏了 | `extract_card.py --left/--top/--right/--bottom ...` |
| 官网没有某张卡 | 走流程 B 截图补齐 |
| Python 找不到 | 用 `D:\ProgramApp\Python\python-3.13.14\python.exe`，见 `run_extract.bat` |
