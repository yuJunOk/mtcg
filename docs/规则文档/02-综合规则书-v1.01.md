## 0. 前言

**001.** 漫威对战卡牌《超英击战》是基于漫威 IP 研发的集换式卡牌游戏，以下简称【游戏】。

**002.** 游戏背景：多元宇宙能量暴走，时间线互相纠缠，无数宇宙濒临毁灭。玩家作为时间守护者联合多方势力作战。

**003.** 综合规则书为规则详解，用于获得游戏的最大限度解答。

**201.1** 角色卡为游戏用卡，用于卡组构筑。  
**201.2** 属于【卡】和【卡牌】定义。  
**201.3** 正面信息：颜色、等级、名称、环境、特征、效果、攻击距离、战力、编号、稀有度、颜色辅助、版权标。  
**201.4** 即使种类变更，一般 **不失去** 上述正面信息。

#### 201.5 颜色

- 左上宝石标识；共 **6 色**：红、黄、蓝、绿、橙、紫

- 含全部文字（标点、称号、姓名）

- 名称左下 `S` + 数字；随产品更新

#### 201.9 特征

- 名称右下斜体；可作为效果参照

#### 201.10 效果

含 **效果类型、效果文本、能力**。

- 红底白字标记；有效区域/要求为黑底白字，斜杠分隔

**201.10.e 常驻型效果**

- 绿底白字标记

**201.10.f 启动型效果**

**201.10.g 能力**

## 3. 游戏进阶

### 301. 核心规则

#### 301.1 优先级

```
效果文本【不能】 > 效果文本【能】 > 规则文本【不能】 > 规则文本【能】
```

#### 301.2 复数

涉及复数张卡的动作，按 **单张复数次** 处理。

#### 301.3 卡牌拥有者

以该卡构筑卡组的玩家；含冲击卡与指示物。

| 动作 | 去向 |
| --- | --- |
| 移回手牌 / 卡组 / 洗回卡组 | 拥有者对应区域 |
| 撤退 | 拥有者撤退区 |
| 裁剪 | 拥有者虚空区 |
| 冲击卡移回/洗回 | 拥有者冲击卡组 |

#### 301.4 卡牌控制者

卡牌所处 **场上** 的所属玩家。

#### 301.5 卡牌指示物

- 需提前准备；**不构筑进卡组**
- 放置于不影响游戏的区域
- 仅可查看 **自身** 指示物
- 离场后放回 **原处**
- 重要信息（名称、种类等）记在指示物上

#### 301.6 原本

卡牌 **印刷的正面信息**。

#### 301.7 此卡

**301.7.a** 【此卡】= 拥有此效果的卡牌本身，也是效果源头。  
**301.7.b** 效果作用于源头（【此卡】或拥有此效果的卡牌本身）时，**不存在目标指定**。

> ~~301.7.c~~（v1.01 **已删除**）

#### 301.8–301.11 数值边界

| 属性 | 最小值 | 最大值 | 备注 |
| --- | --- | --- | --- |
| 战力 | 0 | 无上限 | 减至最小值时，超出部分仍「存在」 |
| Lv | 0 | 无上限 | 同上 |
| R | 0 | 无上限 | 同上 |

**301.9** 受伤 = 当前战力 **低于原本战力** 且 **不为 0**。

#### 301.12–301.14 放置与盖放

| 术语 | 定义 |
| --- | --- |
| **放置** | 正面朝上置入指定区域 |
| **盖放** | 背面朝上置入指定区域 |
| **盖伏** | 基地角色因特定情况翻面至背面；状态刷新，已作用效果结束 |

#### 301.15 舍弃

手牌/卡组中的卡因规则或效果移至 **撤退区**。

#### 301.16 撤退

场上卡因以下情况移至撤退区：

- 角色战力因效果减至 **0**（**锁定撤退**）
- 【撤退角色】规则/效果结算
- 结附卡/盖卡受【撤退卡牌】效果或规则

#### 301.17 裁剪

卡牌置入 **虚空区**。

#### 301.18 替换

- 2 张卡互相替换，**交换当前状态与结附卡**
- 场上 2 卡互换 = **移动**；其他区域组合见 301.18.d–g
- 若替换会导致不能移动的卡移动 → **不能结算**

#### 301.19 号召

| 等级 | 规则 |
| --- | --- |
| **Lv3 及以下** | 手牌角色 **直接放置** 到我方场上 |
| **Lv4 及以上** | 须 **撤退** 场上合计 Lv = 号召角色 Lv 的角色，再放置 |

卡牌/规则中的【号召】均适用；与 **行动号召**（303.2.a.3.1.2）、**应对号召**（303.2.a.4.3.2.3.1、303.2.a.5.2.1）相关。

#### 301.20 破绽

玩家 **空置的战区**。

#### 301.21 盖卡

- 因效果/规则盖放或盖伏后变为盖卡
- 属于【卡】【卡牌】；**失去效果**；视为 **非公开**
- 正面信息 **不能作为参照**
- 双方 **仅可查看各自盖卡**
- Lv4+ 号召时，可撤退盖卡满足需求，**每张计 Lv1**
- 离场时以盖卡种类、失去效果状态进入新区域，再恢复应有种类与状态

#### 301.22 翻开盖卡

盖卡因效果翻开 → 变回角色卡；**不存在【当前回合放置进场】状态**。

#### 301.23 战区移动

战区 ↔ 战区；效果导致的同样视为战区移动。

#### 301.24 战基移动

战区 ↔ 基地区；效果导致的同样视为战基移动。

#### 301.25 角色卡结附

- 角色叠于另一角色下 → **结附卡**
- 不能对已结附的父卡再次结附
- 父卡移动时结附卡 **跟随**；结附卡移动时父卡 **不跟随**
- 父卡移回手牌/卡组顶/底/洗回时，多张结附卡按 **结附先后顺序** 依次跟随（v1.01 修订，原为任意顺序）
- 结附卡与父卡 **同区域**，**不计区域上限**
- 父卡非角色卡时，结附卡 → 撤退区
- **301.25.m** 结附卡按结附顺序叠放，后结附的在下（v1.01 新增）
- **301.25.n** 玩家 **不能改变** 结附顺序（v1.01 新增）

#### 301.26 结附卡解除

结附卡因效果离开父卡进入指定区域 → 变回角色卡；解除属于 **移动**。

#### 301.27 查看

查看目标卡正面信息；**不需** 对方确认。

#### 301.28 展示

双方确认目标卡正面；**不导致** 卡离开所在位置。

#### 301.29 随机

正面信息不可知时，由 **对手** 执行随机动作。

#### 301.30 洗回卡组

目标卡放回卡组并 **洗匀**。

#### 301.31 获得 / 301.32 失去

对 Lv±X、R±X、战力±X、能力、效果、特征的获得与失去。

- 失去负值 **无效**
- 同一内容同时获得与失去 → **失去优先**

#### 301.33 失去效果

失去类型、文本及全部能力内容；之后获得的效果也失去。

#### 301.34 最多 X

可选 0~X；选 0 视为 **效果未结算**。

#### 301.35 任意

可选 0~最大值；选 0 视为 **效果未结算**。

#### 301.36–301.37 名称/特征含有 [A]

[A] 文本须 **连续**。

#### 301.38 如此做后

【如此做后】之前文本 **全部成功结算** 后，才能结算之后文本。

#### 301.39 免疫

不能成为卡牌效果的 **目标**。

#### 301.40 Lv、R、战力±

仅 **获得 Lv±X / R±X / 战力±X** 的效果满足对应 ± 条件。

#### 301.41 Lv、R、战力变更

触发型/启动型与常驻型增减、变更的 **叠加与覆盖** 规则（详见原书 301.41.a–n）：

- 触发型/启动型变更 vs 触发型/启动型增减 → 前者结束，后者生效
- 常驻型变更 vs 常驻型变更 → 前者结束
- 常驻型变更 vs 触发型/启动型变更 → 前者结束，**以常驻型变更为最终**
- 常驻型变更 + 常驻型增减 → 以前者为基础叠加
- Lv/R/战力 **互相替换** 属于 **变更**

#### 301.42–301.44 区域限制消除

先离场后放置、或成功替换时，后段放置/替换 **不受区域限制**。

#### 301.45 离场

场上卡离开场上 → 场外；状态刷新为新卡；场外恢复 **原本状态**；种类已变更者先以变更后状态进入新区域再恢复。

### 303. 开始游戏

#### 303.1 游戏准备

与快速入门一致：洗匀 50 张卡组、9 张冲击卡组 → 决定先后 → 抽 6 → mulligan（先攻先）→ 开始。

#### 303.2 游戏流程

##### 303.2.a.1 回合开始

触发回合开始效果 → 结算完毕 → 下一阶段。

##### 303.2.a.2 抽卡阶段

回合玩家 **抽 2 张** → 结算完毕 → 下一阶段。

##### 303.2.a.3 行动阶段

可任意顺序：

| 行动 | 限制 |
| --- | --- |
| **303.2.a.3.1.1 基地部署** | 手牌 1 张盖入基地 → 抽 1；**每阶段最多 1 次** |
| **303.2.a.3.1.2 行动号召** | 号召 1 角色；**每阶段最多 3 次**；先攻首回合 **最多 1 次** |
| **303.2.a.3.1.3 战基移动** | 选 1 角色战基移动；每角色每阶段 1 次；**本回合进场者不能** |
| **303.2.a.3.1.4 启动效果** | 启动角色 **启动** 与 **应对·启动** 效果 |

宣布行动阶段结束 → 战斗阶段。

##### 303.2.a.4 战斗阶段

**303.2.a.4.1** 先攻 **第一回合跳过**。

**303.2.a.4.2** 顺序：

1. 调整最多 4 张战区角色位置（**不算移动**）
2. 按 **先锋 → 侧翼 → 后卫** 攻击

**303.2.a.4.3 单次战斗流程**

**303.2.a.4.3.1 目标步骤**

- 在 R 内选 1 敌方角色或破绽 → 发生战斗
- **距离规则**（303.2.a.4.3.1.1.1–5）：后卫↔侧翼=1，侧翼↔先锋=1，己先锋↔敌先锋=1，敌先锋↔侧翼=1，侧翼↔后卫=1
- 攻击角色 R=0 / 离场 / 不能攻击 → 未结效果结算后 **战斗结束**（303.2.a.4.3.1.3–5，v1.01 新增 1.4–1.5）

**303.2.a.4.3.2 应对步骤**

- 敌方先选 → 我方选，轮流
- 目标不符 → 返回目标步骤
- 三选一：① 应对号召（双方各 **1 次/回合/本步骤**）② 应对·启动 ③ 不行动
- 双方连续不行动 → 步骤结束
- 攻击角色 R=0 / 离场 / 不能攻击 → 战斗结束（303.2.a.4.3.2.5–7，v1.01 新增）

**303.2.a.4.3.3 判定步骤**

- **角色 vs 角色**：战力大者胜，败者撤退；相等则 **相杀** 双方撤退
- **角色 vs 破绽**：冲击卡组顶 1 张 → 时间线
- 效果结算完毕 → 战斗结束

**303.2.a.4.4–4.7** 每角色每回合 1 次攻击；宣布攻击锁定流程；R=0 不能攻击；选择不攻击则 **失去** 该次机会。

**303.2.a.4.8–4.10 攻击阶段推进**（v1.01 优化）

当前行无角色 / 无攻击机会 / 角色不能攻击 → 进入下一行或结束阶段：

- 4.8：先锋 → 侧翼
- 4.9：侧翼 → 后卫（**4.9.1** 两翼各有 1 角色时可自定攻击顺序）
- 4.10：后卫结束 → 阶段结束

##### 303.2.a.5 应对阶段

与战斗应对步骤类似：敌方先选 → 三选一（应对号召 **各 1 次/阶段**、应对·启动、不行动）→ 双方连续 pass 结束。

##### 303.2.a.6 回合结束

1. 触发回合结束效果  
2. 终止「仅本回合有效」效果  
3. 手牌 **> 9** → 舍弃至 9  

→ 回合结束，对方回合开始。

### 304. 效果进阶

#### 304.1 触发型效果

- 含「可以」= 可选；否则必发
- 触发后立即结算；尽量完全结算
- 多个触发 **逐个** 结算；未结算的保持待处理
- 同一玩家同时多个 → **自选顺序**
- 双方同时 → **回合玩家先**（自选顺序），再非回合玩家
- 结算中再触发 → 先完成当前，再处理新触发
- 同一规则动作/效果同时触发多个 → 视为 **同时**
- 结算中手牌变化满足新条件 → 该时点 **同时触发**

#### 304.2 启动型效果

- 启动后立即结算
- 须 **存在可结算效果** 才能启动
- 含「如此做后」→ 须 **能完成前置动作** 才能启动
