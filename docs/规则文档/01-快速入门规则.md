## 背景

多元宇宙的能量持续暴走，对撞事件让每条时间线互相纠缠侵蚀，无数个宇宙将因此毁灭。

玩家扮演 **时间线的守护者**，构筑超英卡组，在多元宇宙中击战。联合多方势力共同作战，维度大战一触即发。

---

## 卡牌种类

### 角色卡

玩家用于对战、构筑卡组的核心卡牌。

| 字段 | 说明 |
| --- | --- |
| **等级 (Lv)** | 左上角，Lv1–Lv6 |
| **颜色** | 左上角宝石，红/黄/蓝/绿/橙/紫 |
| **编号** | 右上角，如 `BP01-020` |
| **稀有度** | 右上角字母，如 R、SR 等 |
| **名称** | 卡牌名称（含称号） |
| **环境** | 名称左下，如 S1 |
| **特征** | 名称右下，如「人类 / 复仇者联盟」 |
| **效果** | 效果类型 + 效果文本 |
| **攻击距离 (R)** | 右下，如 R-1 |
| **战力** | 右下数值 |
| **颜色辅助** | 左下六色指示灯 |

**示例效果（浩克）：**

> [触发 场上] 此卡因号召放置进场时，裁剪我方撤退区 1 张红色角色。如此做后，我方抽 1 张卡。

### 冲击卡 (Rush Point)

- 代表玩家 **走向胜利的步伐**
- **不进入** 主卡组构筑
- 单独组成 **冲击卡组**（9 张）

## 对战区域

### 区域一览

| 区域 | 说明 | 上限 |
| --- | --- | --- |
| **先锋区** | 战区前排 | 1 |
| **侧翼区** | 战区左右两翼（共 2 格） | 各 1 |
| **后卫区** | 战区后排 | 1 |
| **基地区** | 角色卡 + 盖卡 | 6 |
| **撤退区** | 被撤退/舍弃的卡 | 无 |
| **虚空区** | 被裁剪（移出游戏）的卡 | 无 |
| **时间线** | 放置冲击卡 | 无 |
| **卡组** | 主卡组（面朝下） | — |
| **冲击卡组** | 冲击卡堆（面朝下） | — |
| **手牌** | 抽到的未打出卡 | — |

**场上** = 战区 + 基地区。

### 卡牌状态

| 状态 | 说明 |
| --- | --- |
| **就绪** | 卡牌竖置 |
| **横置** | 卡牌横置；横置状态下通常不能攻击、防御或启动部分效果 |
| **盖卡** | 背面朝上放置于场上；行动阶段可将任意手牌盖入基地区（不占费用，基地最多 6 张含盖卡） |

### 回合流程概览

```
回合开始 → 抽卡阶段 → 行动阶段 → 战斗阶段 → 应对阶段 → 回合结束
```

## 对战准备

### 主卡组

- **50 张** 角色卡，不多不少
- 角色卡 **最多 2 种颜色**
- **同名卡最多 3 张**

### 冲击卡组

- **9 张** 冲击卡，无其他限制

---

## 胜利条件

满足 **任一** 条件即获胜：

1. 我方 **时间线** 存在 **9 张冲击卡**
2. **对方卡组** 剩余 **0 张**

### 冲击卡获取

> 每当我的角色 **成功攻击对方破绽**（空置战区），可将冲击卡组顶 1 张卡 **正面朝上** 放入我的时间线。

---

## 游戏准备与流程

### 游戏准备（6 步）

1. 双方将构筑好的 **50 张角色卡组** 洗匀，面朝下放入卡组区
2. 双方将 **9 张冲击卡组** 面朝下放入冲击卡组区
3. 以双方约定方式决定 **先攻 / 后攻**
4. 各从卡组顶 **抽 6 张** 作为起始手牌
5. **调整起始手牌（ mulligan ）**：先攻玩家先决定，后攻玩家后决定；将不要的牌 **面朝下置于卡组底**，从卡组顶补等量牌，然后 **洗匀卡组**
6. 游戏开始，先攻玩家进行第一回合

### 游戏流程（每回合 6 阶段）

| 阶段 | 要点 |
| --- | --- |
| **1. 回合开始** | 触发「回合开始时」效果 |
| **2. 抽卡阶段** | 回合玩家 **抽 2 张** |
| **3. 行动阶段** | 见 [行动阶段](#行动阶段) |
| **4. 战斗阶段** | 见 [战斗阶段](#战斗阶段)；**先攻玩家首回合跳过** |
| **5. 应对阶段** | 见 [应对阶段](#应对阶段) |
| **6. 回合结束** | ① 触发回合结束效果 → ② 终止「仅本回合有效」的效果 → ③ **手牌超过 9 张则舍弃至 9 张** |

---

## 行动阶段

本阶段以下行动 **可任意顺序** 进行：

### 1. 基地部署（每回合最多 1 次）

1. 从手牌选 1 张卡 **盖入基地区**
2. **抽 1 张** 卡

### 2. 行动号召（每回合最多 3 次）

- 从手牌 **号召 1 张角色**，放置于 **战区** 或 **基地区**（正面朝上）
- **先攻玩家第一回合** 最多号召 **1 次**

### 3. 战基移动

- 场上 **每张角色** 每回合有 **1 次** 战基移动机会
- 选择 1 张场上角色，在 **战区 ↔ 基地区** 之间移动
- **本回合刚放置进场的角色** 不能战基移动

### 4. 启动效果

- 可启动我方卡牌的 **【启动】** 与 **【应对·启动】** 效果

全部行动完成后进入 **战斗阶段**。

---

## 战斗阶段

> 先攻玩家 **第一回合跳过** 本阶段。

本阶段按 **1 → 2** 顺序进行：

### 1. 调整（每回合 1 次）

- 可调整我方战区 **最多 4 张角色** 的战区位置（先锋 / 侧翼 / 后卫之间互换）
- **调整不属于移动**

### 2. 攻击顺序

按 **先锋区 → 侧翼区 → 后卫区** 顺序进行角色攻击。

- 若侧翼区 **两格各有 1 张角色**，回合玩家可 **自行决定** 两卡攻击顺序
- 每张角色 **每回合 1 次攻击机会**；须处于 **战区** 才能攻击，攻击可选
- 宣布攻击后 **锁定** 该次战斗流程

### 单次战斗三步骤

每张角色按 **① → ② → ③** 进行：

#### ① 目标步骤

- 角色在其 **R 值（攻击距离）** 内，选择敌方战区 **1 张角色** 或 **1 个破绽** 作为目标，发生战斗
- 若攻击角色 R 变为 0、离场或不能攻击 → 结算完未结效果后 **本战斗结束**
- 本步骤触发的效果全部结算完毕后进入下一步

**距离示意（己方 → 敌方）：**

| 区间 | 距离 |
| --- | --- |
| 后卫 ↔ 侧翼 | 1 |
| 侧翼 ↔ 先锋 | 1 |
| 己方先锋 ↔ 敌方先锋 | 1 |
| 敌方先锋 ↔ 侧翼 | 1 |
| 侧翼 ↔ 后卫 | 1 |

上述 5 段相邻位置距离均为 1，构成线性路径：`己后卫─己侧翼─己先锋─敌先锋─敌侧翼─敌后卫`。

> **速记**：从**先锋**攻击时，R-1 打敌先锋、R-2 打敌侧翼、R-3 打敌后卫（最远行）。
> 但从**侧翼**或**后卫**攻击时，需额外跨越己方内部距离，实际所需 R 值更大。完整距离矩阵见 [区域模型与回合流程](./04-区域模型与回合流程.md) §1.2。

#### ② 应对步骤

- **敌方先选 1 个行动**，再 **我方选 1 个行动**，轮流进行
- 若原攻击目标不再符合规则 → 结算完效果后 **返回目标步骤重选**
- 可选行动（3 选 1）：
  1. **应对号召**：号召 1 张拥有 **【应对】** 的手牌角色（本步骤双方 **各最多 1 次**）
  2. **启动应对·启动效果**
  3. **不行动**
- **双方连续不行动** → 本步骤结束
- 若攻击角色 R=0、离场或不能攻击 → 结算完效果后 **本战斗结束**

#### ③ 判定步骤

**角色 vs 角色：**

| 比较 | 结果 |
| --- | --- |
| 我方战力 **>** 对方 | 我方胜，**撤退** 对方角色 |
| 我方战力 **<** 对方 | 对方胜，**撤退** 我方角色 |
| 战力 **相等** | 双方 **相杀**，均撤退 |

**角色 vs 破绽：**

- 判定 **成功攻击破绽**
- 将冲击卡组顶 **1 张** 冲击卡 **正面朝上** 放入时间线

本步骤效果结算完毕后 **本战斗结束**。

---

## 应对阶段

- **敌方先选**，**我方后选**，轮流进行
- 可选行动（3 选 1）：
  1. 号召 1 张拥有 **【应对】** 的角色（本阶段双方 **各最多 1 次**）
  2. 启动 **【应对·启动】** 效果
  3. 不行动
- **双方连续不行动** → 阶段结束

## 名词解释

| 术语 | 定义 |
| --- | --- |
| **号召** | Lv3 及以下：直接从手牌放置到场上。Lv4 及以上：须先 **撤退** 场上合计 Lv 等于该角色 Lv 的角色（或部分用盖卡，每张盖卡计 Lv1），再放置 |
| **破绽** | 玩家 **空置的战区** |
| **盖卡** | 角色因规则/效果盖放或盖伏后变为盖卡；失去效果，视为非公开；仅本人可查看；Lv4+ 号召时盖卡可计 Lv1 |
| **舍弃** | 将手牌或卡组中的卡移至 **撤退区** |
| **撤退** | 将场上卡移至 **撤退区** |
| **裁剪** | 将卡移至 **虚空区**（移出游戏） |
| **结附** | 角色卡叠放在另一角色卡下方，成为 **结附卡**；不占区域上限 |
| **解除** | 结附卡不再叠放，移动到指定区域，变回角色卡 |

## 效果类型与能力

### 效果类型

| 类型 | 触发条件 |
| --- | --- |
| **触发** | 在对应 **区域** 时，满足条件则触发 |
| **常驻** | 在对应 **区域** 时，效果持续生效 |
| **启动** | 在对应 **区域** 时，**行动阶段** 可主动启动 |
| **应对·启动** | 在对应 **区域** 时，可在 **行动阶段 / 应对阶段 / 战斗应对步骤** 启动 |

格式：`[效果类型] [区域/要求] 效果文本`

### 关键词能力

| 能力 | 类型 | 效果摘要 |
| --- | --- | --- |
| **应对** | 常驻·手牌 | 此卡可以 **应对号召** |
| **拦截** | 应对·启动·战区 / 每回合 1 次 | 可被敌方选为攻击目标时，可将该次攻击目标改为此卡 |
| **连击** | 常驻·战区 | 获得 **第 2 次攻击机会** |
| **强袭** | 常驻·战区 | 若此卡 **因攻击战胜**，判定为 **成功攻击破绽** |
| **空袭** | 常驻·战区 | 即便敌方战区有角色，也可 **直接攻击该战区作为破绽** |
| **唯一** | 常驻·场上 | 我方场上不能存在其他 **同名卡**；此效果不能失去 |
