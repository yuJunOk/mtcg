## 游戏概要（一句话）

两名玩家各持 **50 张角色卡组** + **9 张冲击卡组**，通过 **号召** 部署角色、在 **战区** 攻击对手，将冲击卡放入 **时间线** 达 9 张，或 **抽空对方卡组** 即可获胜。

## 后续工程化建议

1. 以 `02-综合规则书-v1.01.md` 的条款编号（如 `303.2.a.4.3.2`）作为规则 ID
2. 区域 / 阶段 / 效果类型优先落地为 `engine` 包内的枚举与状态机
3. 关键词能力（应对、拦截、连击等）可映射为 `engine.effect` 下的能力处理器
4. 卡牌字段对齐综合规则 **201.x**（颜色、等级、R、战力、特征等）
