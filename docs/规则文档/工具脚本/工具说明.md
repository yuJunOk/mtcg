# 工具脚本说明

本目录存放用于从官方微信公众号文章中提取规则文本和图片的辅助脚本。当官方更新规则时，可使用这些脚本快速提取新内容。

---

## 脚本列表

### `_extract_wechat.py`

**语言**：Python 3

**用途**：解析微信公众号文章的 HTML 文件，提取标题、正文文本、图片 URL 和关键文本段。

**输入**：同目录下的 `_temp_quickstart.html` 或 `_temp_rules.html`（从浏览器保存的微信文章页面）。

**输出**：
- 控制台打印文章标题、图片数量、文本预览等摘要信息
- 将图片 URL 列表保存为 `*_imgs.json` 文件

**使用方法**：
```bash
cd docs/规则文档/工具脚本
python _extract_wechat.py
```

---

### `_extract_wechat.js`

**语言**：Node.js

**用途**：功能与 Python 版相同，额外支持**自动下载图片**到本地。会遍历文章中的所有图片 URL，下载到指定的图片文件夹中。

**输入**：同 `_extract_wechat.py`。

**输出**：
- 解析文章信息
- 将图片下载到 `docs/规则文档/快速入门图片/` 或 `docs/规则文档/规则书图片/` 目录
- 生成 `quickstart_meta.json` / `rules_meta.json` 元数据文件

**使用方法**：
```bash
cd docs/规则文档/工具脚本
node _extract_wechat.js
```

## 临时 HTML 文件

| 文件 | 来源 | 说明 |
| --- | --- | --- |
| `_temp_quickstart.html` | [官方快速入门文章](https://mp.weixin.qq.com/s/krqehof_Ek0oI9UCcFg2Dw) | 浏览器保存的网页快照，用于提取规则图片 |
| `_temp_rules.html` | [官方综合规则书文章](https://mp.weixin.qq.com/s/qWZcy5F4BK7_5rGf2KmWWQ) | 浏览器保存的网页快照，用于提取规则图片 |

**保存方法**：在浏览器中打开微信文章页面 → 右键「查看网页源代码」→ 全选复制 → 保存为对应文件名。

---

## 元数据 JSON 文件

| 文件 | 说明 |
| --- | --- |
| `quickstart_meta.json` | 快速入门文章的解析结果（标题、图片 URL、文本预览等） |
| `rules_meta.json` | 综合规则书文章的解析结果（同上） |

这些文件由 `_extract_wechat.js` 自动生成，用于校验提取结果的完整性。

## 官方更新流程

当官方发布新的规则文章时：

1. **在浏览器中打开**新文章链接
2. **保存网页源代码**为本目录下的新 `_temp_*.html` 文件
3. **运行提取脚本**（Python 版查看摘要，JS 版下载图片）
4. **整理规则文本**，更新 `docs/规则文档/` 下对应的 `.md` 文档
5. **更新版本号**和来源链接

如果新文章是对现有规则的修订（如 v1.01 → v1.02）：
- 更新现有文档中的条款内容
- 在文档头部更新版本号和日期
- 在附录中添加更新日志
